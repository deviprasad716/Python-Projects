## Project-11 : Quiz Application

A simple command-line **Quiz Application built with Python**.

The project allows users to answer multiple-choice questions, calculate their score, save the result to a file, and view their previous result.

### Features

- Multiple-choice quiz questions
- Automatic answer checking
- Automatic score calculation
- Save quiz results using file handling
- View previously saved results
- Menu-driven application
- Invalid menu choice handling
